## 你应该安装哪个 Ubuntu 版本？

对于几乎所有人来说：24.04 LTS。它会获得 Canonical 的标准安全更新直到 2029 年，搭载 6.8 内核系列和 Python 3.12，而且几乎所有的安装指南和控制面板都会首先针对它进行测试。

| 版本 | 状态 | 标准安全更新至 | 适用场景 |
| --- | --- | --- | --- |
| Ubuntu 26.04 LTS | 最新 LTS | 2031 | 你想要最新内核，并且可以接受较新的版本 |
| Ubuntu 24.04 LTS | 当前默认版本 | 2029 | 几乎所有新服务器 |
| Ubuntu 22.04 LTS | 成熟稳定 | 2027 | 你的软件是基于 22.04 构建或认证的 |
| Ubuntu 20.04 LTS | 传统旧版 | 2025 年 4 月结束（仅限 ESM） | 你确实无法迁移的旧技术栈 |

20.04 那一行值得再看一眼。它的标准支持窗口已于 2025 年 4 月关闭，因此安全修复现在只能通过 Ubuntu Pro 的 ESM 附加组件获取。如果你要部署全新环境，请直接越过它。

临时版本（如 25.10 等）有 9 个月的支持期。在你不打算频繁维护的服务器上，这会导致强制升级的安排，所以跳过它们。

## 新 Ubuntu VPS 的前 10 分钟

在 Vultr 上部署通常在一分钟左右完成，root 凭据会直接显示在您的面板中。接下来你要做的事情决定了服务器是否可以安全地留在互联网上。四个步骤：

1. **登录并更新所有内容。** 模板只会像构建当天一样新。

   
   ssh root@your-server-ip
   apt update && apt full-upgrade -y
   

2. **创建一个用于日常工作的普通用户**，并将您的 SSH 密钥复制给它：

   
   adduser ops && usermod -aG sudo ops
   ssh-copy-id ops@your-server-ip
   

3. **启用防火墙，先允许 SSH。** UFW 在 Ubuntu 上是禁用的，如果您在启用之前允许 OpenSSH，那么您的下次登录将无法通过：

   
   ufw allow OpenSSH && ufw enable
   

4. **拍个快照。** 现在，趁系统干净的时候。它每月只需几美分，可以将未来的任何错误转化为两分钟的恢复。

如果第 3 步无论如何都出错了，Vultr 的基于浏览器的控制台无需 SSH 即可访问服务器，因此您永远不会被完全锁在外面。从那时起，禁用 SSH 密码验证并开启 `unattended-upgrades` 是最重要的两个更改；它们每个只需编辑一次配置。

## Ubuntu VPS FAQ（常见问题解答）

**Vultr 部署需要多长时间？**
在大多数地区大约一分钟。服务器启动后，root 凭据会立即出现在面板中，您可以立即通过 SSH 登录。

**我以后可以就地升级 Ubuntu 吗？**
可以。`do-release-upgrade` 会一次将服务器移动一个 LTS 版本：例如 22.04 到 24.04，然后 24.04 到 26.04。先拍个快照，并且预期全新的重新部署会比大规模的就地升级更快。

**我能获得 root 权限和专用 IP 吗？**
每个套餐都有完全的 root 权限，包含专用 IPv4，并且在支持的地区提供 IPv6。共享 CPU 意味着核心是共享的；但 IP 和磁盘是您独享的。

**VPS 上有 Ubuntu Pro 可用吗？**
Ubuntu Pro 是 Canonical 面向个人用户免费提供的项目，并且它可以附加到任何机器上：使用来自 ubuntu.com 的 token 运行 `pro attach`，以在标准支持之上增加 Livepatch 和 ESM。

**如果我因防火墙把自己锁在外面了怎么办？**
Vultr 的控制台无需 SSH 即可访问服务器。防止此问题的习惯：在执行 `ufw enable` 之前，务必先执行 `ufw allow OpenSSH`。
